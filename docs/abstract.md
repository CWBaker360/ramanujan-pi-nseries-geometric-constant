# Abstract

This note compares Ramanujan-type modular and hypergeometric acceleration for
\(\pi\) with the geometric N-Series construction of \(\pi_g\). The mechanisms
are distinct: Ramanujan acts through analytic identities, while the N-Series
cancels successive even-power errors in a constructible polygonal sequence.
High-precision tests verify the expected convergence-order ladder \(2,4,6\).
